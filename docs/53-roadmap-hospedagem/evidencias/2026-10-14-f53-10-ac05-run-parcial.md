## O que os testes provam

- **Unitário (`tests/backend/test_pipeline_runner.py`):** o sinal de parada
  (`SIGTERM`) ou o prazo do passo é disparado somente depois que o `execute`
  falso rodou a primeira fonte (gatilho por comportamento, sem contar leituras
  da flag ou do relógio). A segunda fonte fica **não executada e sem chamada de
  fechamento**: `executed == [source1.id]`, `normalize_calls` e `closure_calls`
  contêm só a run da primeira fonte, e os contadores são
  `completed=1, skipped=1`.
- **Banco isolado, entre fontes
  (`test_partial_pass_between_sources_preserves_absences`):** a parada só vira
  verdadeira depois que o coletor da primeira fonte realmente rodou. A fonte
  pulada mantém a run anterior como a mais recente e sua ausência continua
  aberta; a fonte que rodou fecha a própria ausência (dois misses completos
  consecutivos); uma run completa de controle da fonte pulada fecha a ausência.
- **Banco isolado, run PARTIAL
  (`test_complete_run_after_timeout_partial_closes_absences` e
  `test_worker_timeout_preserves_positive_presence_only`):** a run PARTIAL
  (prazo estourado no meio da fonte, depois de persistir `present`; a ocorrência
  de `present` aponta para a run PARTIAL) não é completa e não fecha a
  ausência; a run completa seguinte fecha.
